# Школотворці 13.0 — перша програмна збірка

Самостійна робоча версія, створена на основі архіву репозиторію «Педагополія». Оригінальні файли збережені в `legacy-v12/` для порівняння. Нова реалізація поки **не є повною V13**.

## Запуск

Потрібен Node.js 18+. У каталозі проєкту:

```bash
npm start
```

Відкрити http://localhost:3000. Перевірка структури контенту: `npm test`.

## Реалізовано

- 6 раундів, у кожному 10 тестових питань і педагогічна задача; 60 питань і 6 задач загалом.
- 250 монет за правильне тестове питання; до 2500 за тест, до 2500 за задачу.
- Автозбереження чернеток за кнопкою, відкладання, повторне проходження; монети нараховуються тільки за покращення найкращого результату.
- 12 реформ у довільному порядку, загальна вартість 30 000 монет; немає ліміту 2 реформи на раунд.
- Соло, кімнати викладача на 4/6 учасників, коди кімнат, запити на допомогу, початок і перемикання раундів, пауза й продовження часу.
- Початкова система досягнень і візуальне представлення школи.
- Серверне збереження кімнат у JSON-файл, перевірка відповідей на сервері.

## Що ще не реалізовано

- Повноцінне спільне редагування відкритої відповіді, голосування за її надсилання та оцінювання викладачем.
- 25 шкільних ситуацій (12 500 монет), 38 мініігор (7 500 монет), повна система 19 досягнень, престижу й репутації.
- Повноцінні командні голосування з тай-брейком, відкладенням і надійною більшістю, багатокімнатний кабінет викладача, експорт Excel.
- Автоматичне завершення раунду за таймером, відновлення доступу без токена, постійна БД (PostgreSQL).
- Захист від одночасних змін у спільній чернетці: зараз відповіді в команді можуть перезаписуватися.

**Увага:** файл JSON на Render із тимчасовою файловою системою не гарантує збереження після рестарту або redeploy. Для продакшену необхідна постійна база даних. Поточну збірку не слід розгортати поверх робочої V12.

## V13.1: PostgreSQL та кабінет викладача

- `npm install` і `npm start` для локального запуску. Без `DATABASE_URL` використовується локальний JSON-файл `rooms-v13.json`.
- Для Render задайте `DATABASE_URL` (PostgreSQL connection string) як секретну змінну середовища. Сервер сам створює таблицю `game_rooms` та завантажує збережені кімнати перед відкриттям порту.
- Якщо підключення до PostgreSQL не вдалося, сервер **не запускається**, щоб не створити помилкове відчуття збереження даних.
- `PGSSL=disable` дозволяє вимкнути SSL лише для локальної довіреної бази.
- Викладач може змінити позначку заняття, налаштування відкритих відповідей, тривалість раундів і завантажити деталізований CSV для Excel.
- **Увага:** це проміжна реалізація. Для виробничого розгортання потрібні резервні копії БД, міграції, посилена автентифікація викладачів, тести одночасних запитів і належний контроль персональних даних. Поточна реалізація зберігає повний стан кімнат у JSONB і призначена для одного екземпляра сервера.

## Оновлений вигляд (тестова збірка)
Інтерфейс оформлено у ретропалітрі: бордовий, м'ятний, жовтий, помаранчевий, кремовий; темні контури, великі кнопки та адаптивна верстка. Ігрові персонажі та локації поки представлені базовими елементами й емодзі, а не фінальними ілюстраціями.

## Локальний тестовий запуск
1. Встановіть Node.js 18+.
2. У папці проєкту виконайте `npm install`.
3. Запустіть `npm test`, а потім `npm start`.
4. Відкрийте адресу, яку покаже сервер (типово `http://localhost:3000`).

Для тесту з реальними студентами на Render потрібно окремо налаштувати `DATABASE_URL`, захист доступу, HTTPS і перевірити багатокористувацькі сценарії. Поточна збірка не розгорнута онлайн.

## Тестове розгортання на Render (окремо від V12)

1. Створіть **новий приватний або публічний репозиторій** GitHub, наприклад `shkolotvortsi-13-test`. Завантажте **вміст** папки `Школотворці-13` у корінь репозиторію (щоб `package.json` був у корені). Не змінюйте репозиторій робочої V12.
2. На Render створіть **Postgres** базу даних, якщо вона доступна у вашому тарифі. Збережіть **Internal Database URL**; URL не публікуйте. Перевірте обмеження й політику зберігання обраного тарифу.
3. Render → **New → Web Service** → підключіть новий GitHub-репозиторій. Середовище **Node**; **Build Command:** `npm install`; **Start Command:** `npm start`; **Root Directory:** порожньо, якщо package.json у корені.
4. Web Service → **Environment** → додайте секрет `DATABASE_URL` зі значенням Internal Database URL. Не додавайте `PGSSL=disable` для віддаленої БД. `PORT` вручну задавати не потрібно: сервер читає `process.env.PORT`.
5. Натисніть **Deploy**. У логах перевірте, що немає помилки підключення PostgreSQL. Відкрийте URL формату `https://<service>.onrender.com` — фактичну адресу надасть Render.
6. Тест: створіть кімнату викладача, зайдіть з іншого браузера/пристрою як учень, виконайте завдання, проголосуйте за реформу, перевірте оцінювання, оновіть сторінку й переконайтеся, що стан зберігся. Перезапустіть сервіс і перевірте збереження ще раз.

**Застереження:** поточний сервер тримає стан кімнат у пам’яті й записує їх у PostgreSQL; для тесту використовуйте **один інстанс Web Service**. Система не проходила навантажувального аудиту, автентифікація викладача та захист персональних даних потребують доопрацювання. Не використовуйте справжні прізвища дітей та конфіденційні дані у тестових кімнатах. Без `DATABASE_URL` працює лише локальний JSON-файл, ненадійний для Render.


## Оновлення 13.2 — тестування
Додано покроковий туторіал для викладача, командного та соло режимів; повторний запуск через «❔ Як грати». У збірці також є вкладки «Учні», «Журнал», «Досягнення», три безкоштовні та три платні мініігри, реформи і шкільні ситуації. Автоматичні тести перевіряють структуру контенту, але повний браузерний тест усіх сценаріїв ще потрібен.

Для Render: Root Directory залишити порожнім, якщо package.json знаходиться в корені репозиторію; Build Command: npm install; Start Command: npm start. Перевірити DATABASE_URL в Environment, не публікувати його. Не змінювати сервіс старої V12.


## Версія 13.3
Інтерактивна школа в розрізі з шістьма кімнатами, переглядом учнів і їхніх потреб, панеллю шкільної статистики та шістьма косметичними покращеннями, які зберігаються на сервері. Показники навчання та задоволеності є ігровими індикаторами, не результатами реальних опитувань. Для перевірки створіть нову солокімнату, відкрийте «Школа» та протестуйте покупки після заробітку монет.
